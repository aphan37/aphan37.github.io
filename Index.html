SIEM ENGINEERING

How the data actually flows

This is roughly the path a log takes through a Splunk deployment I help run — from a raw event on a host to something a detection can fire on.

01

Data sources

Linux and Windows hosts, domain controllers, and network devices generating raw event logs around the clock.

02

Forwarders

Universal Forwarders collect at the host; Heavy Forwarders parse and filter out noise before it ever reaches the indexers.

03

Deployment server

Pushes configs and add-ons out to every forwarder through Server Classes — the piece that keeps collection consistent across hundreds of hosts.

04

Custom add-ons

Technology add-ons handle field extraction and sourcetype tagging, tuned per customer environment.

05

Index routing

Props and transforms route each event into the right index — by source, sensitivity, or team ownership.

06

Production

Indexed data becomes SPL searches, dashboards, and detections the SOC actually acts on.

Note: the deployment server manages forwarder configuration, not the log data itself — it runs alongside this flow rather than inside it, which is what keeps steps 01–02 consistent at scale.
